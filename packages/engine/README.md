# `@noeos/verification-engine`

Package boundary for the deterministic, offline-first Noeos verification engine. It supports ESM and CommonJS, has zero runtime dependencies, and is governed by the normative protocol contracts in the repository [`docs/`](../../docs/README.md).

The `1.0.0` release package exposes the reviewed engine API, public types, schemas, profiles, vectors, and ESM/CommonJS boundaries. Verify the release tag, npm provenance, SBOM, and package metadata before integrating a published version.

Repository-wide verification instructions and security reporting channels are available in the [main README](../../README.md) and [`SECURITY.md`](../../SECURITY.md).
