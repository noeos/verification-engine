# `@noeos/verification-engine-cli`

Package boundary for the Noeos command-line interface. It is restricted to the verification engine and standard Node.js APIs so command execution cannot alter the deterministic protocol contract.

No version has been published to npm and the current package exposes no product commands. It remains private until command contracts, conformance evidence, platform compatibility, security review, and release gates are complete.

Repository-wide verification instructions and security reporting channels are available in the [main README](../../README.md) and [`SECURITY.md`](../../SECURITY.md).
