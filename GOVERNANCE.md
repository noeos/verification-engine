# Governance

The repository is governed by the approved normative corpus in `docs/`. Authority and conflict resolution follow `docs/00-gobierno/01-autoridad-documental.md`; this file is an operational summary and cannot override it.

## Initial ownership

`@ddavid07` is the initial product, protocol, security, release, legal/privacy, and documentation owner. Role separation and a recovery-capable second person or provider are mandatory before the stable release gate.

## Decisions

- Approved decisions are changed only through a reviewed ADR that identifies affected requirements, compatibility, migration, security, legal, performance, and release consequences.
- Conversations, inline task comments, and untracked notes are not decision records.
- Known contradictions and open normative decisions block implementation and release.

## Enforcement

Branch rules, CODEOWNERS, DCO, signed commits, required CI, critical-path waiting periods, release environments, and external audits enforce the documented process. A temporary limitation is recorded as a blocking risk; it is never described as compliance.
